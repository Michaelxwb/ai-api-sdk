核心设计亮点

1. 最小接口 + 可选扩展

// 最小必需接口（SDK 只依赖这两个方法）
type SessionStore interface {
  GetMessages(ctx, sessionID, opts) ([]Message, error)
  AppendMessages(ctx, sessionID, msgs) error
}

// 可选扩展接口（通过 type-assert 检测）
type SessionStoreWithLifecycle interface { ... }  // Create/Delete
type SessionStoreWithMeta interface { ... }        // 元数据管理
type SessionStoreWithVersion interface { ... }     // 乐观锁/并发控制

优点：应用层只需实现 2 个方法即可工作，高级特性按需实现。

2. 标准错误类型

var (
  ErrSessionNotFound  = errors.New("session not found")
  ErrSessionConflict  = errors.New("version conflict")
  ErrSessionClosed    = errors.New("session closed")
  ErrStoreUnavailable = errors.New("unavailable")
)

3. 清晰的职责分工
┌────────┬────────────────────────────────────┬──────────────────────────────┐
│  层级  │                职责                │            不负责            │
├────────┼────────────────────────────────────┼──────────────────────────────┤
│ SDK    │ 定义接口、调用 Store、合并历史     │ 具体存储、业务逻辑、权限     │
├────────┼────────────────────────────────────┼──────────────────────────────┤
│ 应用层 │ 实现 Store、管理生命周期、权限控制 │ 不需要了解 Provider API 细节 │
└────────┴────────────────────────────────────┴──────────────────────────────┘
4. 三种存储实现示例

✅ 内存存储（开发/测试）：零配置，快速启动
✅ MySQL/PostgreSQL：关系型数据库，事务保证
✅ Redis：高并发场景，TTL 自动过期

5. Token 限制的灵活处理

type GetOptions struct {
  MaxMessages      int  // 消息数量限制
  MaxTokens        int  // Token 预算（提示）
  KeepSystemPrompt bool // 保留系统提示
}

应用层可以根据 opts 自行截断，也可以返回完整历史让 SDK 截断。

6. 并发安全策略

- SDK 不加锁（避免性能瓶颈）
- Store 实现保证并发安全（事务/原子操作/乐观锁）
- 支持版本号冲突重试（可选）

使用示例对比

// 场景 1：内存存储（最简单）
store := sessionstore.NewMemoryStore()
cli := client.NewClient(cfg, mgr)
cli.SessionStore = store
cli.SessionConfig.AutoCreate = true

resp, _ := cli.ChatSession(ctx, "openai", "session-123", base.ChatRequest{
  Model: "gpt-4",
  Messages: []base.Message{{Role: "user", Content: "hello"}},
})

// 场景 2：Redis 存储（生产环境）
redisStore := sessionstore.NewRedisStore(rdb, 3600*time.Second)
cli.SessionStore = redisStore

// 场景 3：自定义 DB 存储
dbStore := &MyDBStore{db: sqlDB}
cli.SessionStore = dbStore
